# G1I experiment baselines

These compact summaries preserve the decisions made by the isolated G1I experiments.
Raw token traces are runtime/debug artifacts and are intentionally excluded from Git.

- `search_gate_v2.json`: selected one-token Search Gate threshold baseline.
- `legacy_protocol_v1.json`: unconditional legacy tool-session baseline.
- `query_only_v1.json`: query-only comparison; not the selected runtime path.
- `format_stability_v1.json`: four serialization formats under greedy decoding.
- `system_prompt_v1.json`, `system_prompt_v2.json`: P4 prompt selection evidence.
- `p4_real_search_v1.json`: first P4-to-realtime-search baseline.
