## Silent no-op bug found and fixed

Two earlier detached-BPTT runs produced byte-identical adapter files and unchanged Dev loss. The cause was autocast weight caching: BF16 LoRA weight casts created during no-gradient prompt prefill were reused in supervised response windows, so every LoRA parameter was disconnected from autograd.

The isolated trainer now disables autocast weight caching for detached-BPTT training and fails immediately when the first-step gradient audit finds no non-zero trainable gradient. The corrected step-50/100/150/200 adapter hashes are all different.
